# F1 Dashboard

A landscape-first F1-inspired personal dashboard designed for iPhone.

## Features

- Live analog clock
- Digital time
- Current date and day
- Live weather
- Personal notes with local auto-save
- Landscape-first iPhone layout
- Installable as a PWA
- Vercel-ready

## Tech Stack

- Next.js
- React
- TypeScript
- CSS
- Open-Meteo weather API

## Run locally

```bash
npm install
npm run dev
